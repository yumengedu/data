# Mental Imagery fNIRS Data

This repository contains behavioral and fNIRS data from a study examining imagery-driven disgust learning and generalization.

## Generalization Sequences

Participants were assigned to one of three generalization sequences:

- `disneu` — **Within-imagery sequence**: generalization from a disgust-imagery cue to a neutral-imagery cue.
- `disno` — **Imagery-to-perception sequence**: generalization from a disgust-imagery cue to a no-imagery cue.
- `neuno` — **Control sequence**: generalization from a neutral-imagery cue to a no-imagery cue.

## Data File

- `mental-imagery fnirs.xlsx` — behavioral and fNIRS data used in the study.
